# Captain Battleship — Стол Капитана

Веб-игра «Морской бой» 10×10 с циклом смены суток (**Рассвет → День → Закат → Ночь**), сетевым режимом по коду комнаты (PeerJS / BroadcastChannel) и боем против бота.

## Состав проекта
- `index.html` — основной код интерфейса, логики боя, сети и смены фаз суток
- `assets/tracks/day.mp3` — первая часть фонового трека (Рассвет / День)
- `assets/tracks/night.mp3` — вторая часть фонового трека (Закат / Ночь)
- `manifest.json` — манифест веб-приложения
- `sw.js` — Service Worker для кэширования файлов
- `.nojekyll` — отключение Jekyll при публикации на GitHub Pages
- `package.json` — параметры проекта и команда локального запуска
- `.gitignore` — правила игнорирования системных файлов
