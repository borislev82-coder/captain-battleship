# Captain Battleship v17 — большие поля и 3D-флот

## Запуск на Windows

1. Установите [Node.js LTS](https://nodejs.org/) версии 22 или новее. Распакуйте ZIP целиком.
2. Запустите **start-windows.cmd** и оставьте окно открытым. Команда для терминала в папке игры — **node server.js**. Устанавливать пакеты отдельно не требуется.
3. На компьютере с сервером откройте **http://localhost:8080**. Если играете с участником в той же сети Wi-Fi, откройте игру по адресу **LAN**, который напечатан в окне сервера. Оба игрока должны пользоваться этим адресом. Если Windows спросит о доступе к сети, разрешите его для частной сети. В гостевых сетях роутер может блокировать связь между устройствами.
4. На стартовом экране нажмите кнопку входа, введите **1234** и выберите «Морской бой». Это экран исходной игры. Код доступа виден в браузере и служит только частью интерфейса.
5. Введите имя, выберите звание, нажмите **🎲 Код**, затем **Войти в комнату**. Первый капитан задаёт размер поля.
6. В комнате нажмите **🔗 Ссылка** и отправьте её сопернику. Она открывает лобби с заполненным кодом комнаты. Сопернику остаётся указать имя и нажать **Войти в комнату**. При входе без ссылки он может ввести код комнаты вручную на том же сервере.
7. Оба капитана расставляют флот и нажимают **Готов к бою**. Для проверки на одном компьютере используйте обычное окно браузера и окно InPrivate.

Если порт занят, задайте другой в PowerShell командой **$env:PORT = '8081'**, затем выполните **node server.js**. Используйте новый порт в ссылках. Для игры только на этом компьютере перед запуском можно задать **$env:HOST = '127.0.0.1'**.

Если хотите играть с ботом, войдите в комнату и нажмите **Сыграть с ботом**, пока комната свободна. Тренировка освобождает ваше место на сервере.

## Старшие звания

| Звание | Размер | Кораблей | Типов | Палуб | Бочек | Шлюпок |
| --- | --- | --- | --- | --- | --- | --- |
| Гросс-Адмирал | 30×30 | 55 | 19 | 177 | 18 | 10 |
| Лорд Адмирал | 50×50 | 153 | 30 | 492 | 50 | 28 |
| Король Пиратов | 100×100 | 552 | 46 | 2000 | 180 | 109 |

Перед боем выберите фигуру и расставьте её на своём поле или нажмите **Переставить флот** для случайной расстановки. На полях 50×50 и 100×100 каждое поле имеет свой список секторов. Переход между секторами сохраняет расстановку и использует сквозные координаты. На поле 100×100 есть 25 секторов по 20×20 клеток.

**Импорт поля JSON** читает файл редактора на компьютере игрока. Для звания Лорд Адмирал подходит lord-admiral-50x50.json, для Короля Пиратов — korol-piratov-100x100.json. Импорт сохраняет координаты и повороты кораблей. Эти JSON не входят в общую копию игры. 30×30 поддерживает ручную и случайную расстановку из ведомости, а также импорт совместимого файла.

Кнопка **3D-флот** открывает ваш флот и позволяет рассмотреть каждый тип отдельно. На больших полях обзор показывает выбранный сектор своего поля. В нём используются корабли, вода, материалы и качка из проекта V8, без персонажей. Для выстрела и расстановки закройте обзор и используйте клеточное поле.

## Управление полем

Выберите **3D** или **Схема**. Колесо мыши меняет масштаб. Для перемещения внутри поля или сектора удерживайте правую кнопку мыши, используйте WASD или стрелки. На телефоне двигайте поле двумя пальцами. Сведение и разведение пальцев меняет масштаб.

## Туман и выстрелы

На своём поле сразу видно море и корабли. Клетки противника скрыты туманом, пока по ним не выстрелили. Туман в цели краснеет, ядро падает в клетку, и после всплеска видно воду при промахе или плавающие обломки при попадании и потоплении. Соседние клетки, которые правила исключают после потопления, остаются в тумане, если в них не стреляли.

## Публичный адрес

Загрузите распакованные файлы в репозиторий и подключите его к хостингу. Один процесс обслуживает страницу, музыку и комнаты. После публикации оба капитана открывают выданный хостингом HTTPS-адрес, создают комнату и делятся ссылкой тем же способом. Проброс портов на домашнем роутере для этих вариантов не нужен.

| Вариант | Настройка |
| --- | --- |
| [Render Web Service](https://render.com/docs/web-services) | Выберите Web Service с Node.js. Build Command — **npm install**, Start Command — **npm start**, Health Check Path — **/healthz**. Используйте выданный адрес сервиса. |
| [Railway](https://docs.railway.com/networking/public-networking) | Создайте сервис из репозитория. Команда запуска — **npm start**. В разделе Public Networking нажмите Generate Domain. |
| Собственный VPS | Запускайте **node server.js** одним постоянно работающим процессом с **HOST=127.0.0.1**. Направьте HTTPS-запросы с домена на порт процесса через обратный прокси. |

Платформы могут приостанавливать сервис или перезапускать его при обновлении. Для партий без таких перерывов настройте постоянно работающий экземпляр. **GET /healthz** возвращает результат проверки доступности процесса. Публикация только index.html на статическом хостинге оставит игру без сервера комнат.

## Правила и ограничения

- В комнате два места. Автоматический код состоит из восьми символов. Вручную можно ввести от 4 до 10 латинских букв или цифр. Любой, кто знает код, может занять свободное место. Для закрытой игры передавайте случайный код только сопернику.
- Сервер проверяет формы кораблей и отсутствие соприкосновений, очередность и повторные выстрелы. При попадании ход сохраняется, при промахе переходит сопернику. Браузер получает только открытые клетки поля противника.
- Браузер проверяет обновления примерно раз в секунду. Если связь пропала, оставьте вкладку открытой. Примерно через 12 секунд без связи сервер приостанавливает стрельбу по отключившемуся игроку. Место сохраняется до двух минут. При выходе кнопкой «В лобби» или по истечении этого срока партия сбрасывается, и оставшийся игрок может пригласить соперника заново.
- Обновление страницы и закрытие вкладки теряют ключ игрока. Если комната заполнена после перезагрузки вкладки, подождите освобождения места или создайте новый код. Чтобы сразу освободить место перед сменой вкладки, используйте «В лобби».
- Комнаты хранятся в памяти одного запущенного процесса. Перезапуск сервера удаляет партии. Ограничение — до 500 одновременно существующих комнат. Для этого выпуска оставьте один экземпляр приложения. Аккаунтов и истории матчей нет.
- Ссылку с **localhost** может открыть только компьютер с запущенным сервером. Для общей Wi-Fi сети используйте адрес **LAN**, а для игры через интернет — публичный HTTPS-адрес.
